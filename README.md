# 보카로 트렌드

오타쿠 랜덤플레이댄스를 보다가 이런 행사에 나오는 곡들은 웰노운이고 좋은 곡들이라는 생각이 들었습니다.

그래서 여러 행사들에 나오는 곡들을 조사해서 리스트를 만들어봤습니다.

복잡한 구조보다는 우선 `songs.json`만 잘 관리하면 그걸 적절히 보여주도록 개발했습니다.

## 구조

```
index.html   목록 화면 (검색, 태그 필터, 정렬)
songs.json   곡 데이터
style.css    스타일 (라이트/다크 모드 자동 전환)
```

## 로컬에서 보기

`songs.json`을 `fetch`로 읽기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다. 로컬 서버를 띄워서 확인하세요.

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 열면 됩니다.

## 곡 추가하기

`songs.json` 배열에 항목을 추가합니다.

```json
{
  "id": "sm15630734",
  "title": "千本桜",
  "producer": "黒うさP",
  "vocal": ["初音ミク"],
  "year": 2011,
  "tags": ["神話入り", "화풍"],
  "why": "추천 근거 한 줄"
}
```

| 필드       | 설명                                                              |
| ---------- | ----------------------------------------------------------------- |
| `id`       | 니코니코 동화 영상 ID (`sm...`). 썸네일, 임베드, 원본 링크에 사용 |
| `title`    | 곡 제목                                                           |
| `producer` | 작곡가(P)                                                         |
| `vocal`    | 사용한 보컬 음원 목록                                             |
| `year`     | 투고 연도                                                         |
| `tags`     | 필터에 쓰이는 태그 목록                                           |
| `why`      | 추천 근거                                                         |

영상 임베드는 썸네일을 클릭했을 때만 불러옵니다. 곡이 많아도 첫 로딩이 느려지지 않습니다.

## 배포

GitHub Pages: 저장소 Settings → Pages에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 지정합니다.
